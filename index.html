برنامج Hello World بلغة HTML

هذا مثال بسيط لصفحة HTML تعرض جملة "Hello World" مع شرح لكيفية عمل الكود.

Hello World!

كود HTML

<!DOCTYPE html>
<html>
<head>
    <title>Hello World</title>
</head>
<body>
    <h1>Hello World!</h1>
</body>
</html>

معلومات عن كود HTML

- <!DOCTYPE html> : يحدد نوع المستند كصفحة HTML5
- <html> : العنصر الجذر الذي يحتوي على جميع عناصر الصفحة
- <head> : يحتوي على معلومات عن الصفحة مثل العنوان
- <title> : يحدد عنوان الصفحة الذي يظهر في شريط المتصفح
- <body> : يحتوي على محتوى الصفحة المرئي للمستخدم
- <h1> : عنصر لعنوان رئيسي بحجم كبير
